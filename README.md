## 🏪 Sistema de Gestión para Tiendas

DigitalMarKet es un software básico desarrollado en Python para pequeñas tiendas y negocios locales que desean comenzar a digitalizar el control de sus productos. El sistema permite registrar y visualizar productos mediante un menú interactivo en consola.

---

# ✨ Características

- Registro de productos
- Visualización de productos registrados
- Menú interactivo
- Sistema simple y fácil de usar
- Proyecto educativo para prácticas de documentación y control de versiones

# ⚙️ Instalación

1. Clonar el repositorio:

```bash
git clone https://github.com/JandryCordova/DIgitalMarKet.git
```

2. Ingresar a la carpeta del proyecto:

```bash
cd DIgitalMarKet
```

3. Ejecutar el programa:

```bash
python productos.py
```

---

# ▶️ Uso del Sistema

Al ejecutar el programa aparecerá un menú interactivo con las siguientes opciones:

```text
1. Registrar producto
2. Mostrar productos
3. Salir
```

El usuario podrá registrar productos y visualizar la lista de productos almacenados durante la ejecución del programa.
